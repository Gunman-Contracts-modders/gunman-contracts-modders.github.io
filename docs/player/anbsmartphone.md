# ANBSmartphone

The smartphone the player wears on the wrist.

## Functions

### `grabFromWrist`

`grabFromWrist()`

Triggered when
:   The player grabs the phone from the wrist.

Hook
:   Postfix

We use it to
:   Play the wrist effect on the left side.

### `retractToWrist`

`retractToWrist()`

Triggered when
:   The phone goes back to the wrist.

Hook
:   Postfix

We use it to
:   Play the wrist effect on the left side.

## Variables

The mod reads no variables in these functions.
